# q1: How many players are there for each nationality?
## Query contract
**Natural language:** How many players are there for each nationality?

**Reference SQL**
```sql
SELECT nationality, COUNT(*) AS player_count FROM player WHERE nationality != '' GROUP BY nationality
```

### Why QuWARTS differs
- **Pipeline stage:** Nationality names and missing values
- **Root cause:** QuWARTS did not use one clear set of nationality names. It also missed many nationality values.
- **Why the system made this choice:** QuWARTS changes a value only when there is clear proof that the change is right. This reduces guessing, but it leaves difficult names unchanged.
- **Why the checks did not catch it:** Names such as Azerbaijan and Azerbaijani both appear reasonable. The checks cannot tell that they should be placed in the same group.
- **Why this query failed:** The same nationality appears under several names, while missing values make the American group too small. The question counts each name as a separate group.

**What I saw in the run**
- QuWARTS counts 82 American players, while the ground truth has 116.
- Gold labels such as American-born naturalized Azerbaijani, Dominican, Dutch, and Nigerian-American are absent while Azerbaijan, Dominican Republic, Netherlands, and Nigerian appear.
- The output has 24 groups versus 22 in gold: six gold groups are missing, eight unmatched labels are added, and the American count is wrong.

### Why DocETL differs
- **Pipeline stage:** Nationality output
- **Root cause:** DocETL saved some full data objects as nationality names. It also did not join different names for the same nationality.
- **Why the system made this choice:** The output rule only checks that nationality is text. It does not check that the text is a normal nationality name.
- **Why the checks did not catch it:** A full data object can still be saved as text, so it passed the check.
- **Why this query failed:** The broken text became a group name. Shorter nationality names also created missing and extra groups.

**What I saw in the run**
- The q1 extraction has all 141 document rows, but five nationality values are empty and the American group is 102 versus 116 in gold.
- Eight extra groups contain full data objects or unrelated text instead of nationality names. One broken group contains five rows with {"nationality": "American"}. Azerbaijan and Nigerian are also used in place of longer nationality names.
- American-born naturalized Azerbaijani is shortened to Azerbaijan, and Cameroonian-American and Greek-American are missing as exact groups.
