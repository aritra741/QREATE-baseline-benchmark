# q2: For each current NBA team, what is the average number of NBA championships won by its listed players?
## Query contract
**Natural language:** For each current NBA team, what is the average number of NBA championships won by its listed players?

**Reference SQL**
```sql
SELECT p.team, AVG(p.nba_championships) AS avg_championships FROM player p JOIN team t ON p.team = t.team_name GROUP BY p.team
```

**QuWARTS compiled SQL**
```sql
SELECT p.team, AVG(p.nba_championships) AS avg_championships FROM player p JOIN team t ON p.team = t.team_name GROUP BY p.team
```

The SQL contracts are equivalent unless the two SQL blocks visibly differ. Therefore, documented failures below are downstream of intent/compilation.

### Why QuWARTS differs
- **Pipeline stage:** Teams and title counts
- **Root cause:** QuWARTS often missed a player's current team or NBA title count.
- **Why the system made this choice:** It kept team and number mentions from the documents so that it would not lose useful facts. It did not always choose the current fact.
- **Why the checks did not catch it:** A team name or number can appear in the document and still describe the wrong time or event.
- **Why this query failed:** The average used only a small and unfair set of players. The calculation was correct, but the input rows were wrong.

**What I saw in the run**
- Team is missing from 62 of 160 player rows. NBA title count is missing from 114 rows.
- Five ground-truth teams are missing. Charlotte Hornets is an extra team in the result.
- Most aligned averages differ substantially (for example Chicago 0.3333→3.0 and San Antonio 1.2→2.3333), which is consistent with averaging a small, biased subset rather than an aggregation bug.

### Why DocETL differs
- **Pipeline stage:** Missing numbers and team names
- **Root cause:** DocETL used -1 for missing title counts. It also used different forms of the same team name.
- **Why the system made this choice:** Player data and team data were built separately. Missing numbers stayed as -1, and team names were not cleaned together.
- **Why the checks did not catch it:** -1 is still a number, and names such as Celtics and Boston Celtics are both normal text.
- **Why this query failed:** The -1 values lowered the averages. Different team names also stopped valid players from matching their teams.

**What I saw in the run**
- The q2 player extraction has 132 rows, of which 110 have nba_championships=-1 and 53 have an empty team.
- The team table uses names such as Celtics, Bulls, and Mavericks. Player rows use Boston Celtics, Chicago Bulls, and Dallas Mavericks. These different names do not match.
- Negative averages such as Brooklyn=-1.0, Detroit=-0.4, and Miami=-1.0 show that -1 was treated as a real title count.
