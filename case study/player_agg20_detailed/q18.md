# q18: What is the average city population for each state?
## Query contract
**Natural language:** What is the average city population for each state?

**Reference SQL**
```sql
SELECT state_name, AVG(population) AS avg_population FROM city WHERE state_name != '' GROUP BY state_name
```

**QuWARTS compiled SQL**
```sql
SELECT state_name, AVG(population) AS avg_population FROM city WHERE state_name != '' GROUP BY state_name
```

The SQL contracts are equivalent unless the two SQL blocks visibly differ. Therefore, documented failures below are downstream of intent/compilation.

### Why QuWARTS differs
- **Pipeline stage:** Numeric scope and time
- **Root cause:** Population values came from different dates or geographic areas, but the table has no scope or date attached to each number.
- **Why the system made this choice:** The raw view keeps a source-backed population number as one scalar value. It does not resolve city proper, metro area, and year.
- **Why the checks did not catch it:** All values are plausible numbers with source spans. Full state coverage makes the structural checks look strong even when the measures are not comparable.
- **Why this query failed:** Every state group survives, but the wrong population version changes six state averages.

**What we saw in the run**
- The city table has 29 rows and q18 reproduces all 22 gold state groups with no extras.
- Wrong examples include New York 8,804,190 versus 8,258,035, Utah 1,257,936 versus 200,133, and Texas averaging 2,072,845.33 versus 1,684,387.
- Because every key aligns, the failure is value extraction rather than grouping or SQL compilation.

### Why DocETL differs
- **Pipeline stage:** Missing-value handling and category coverage
- **Root cause:** Many state names were blank, and unknown populations were stored as -1.
- **Why the system made this choice:** The Map prompt permits empty text and -1. There is no later missing-value mask or geographic scope check.
- **Why the checks did not catch it:** Both markers fit the output schema and SQLite AVG treats -1 as a real number.
- **Why this query failed:** Blank states remove groups, while -1 lowers averages such as Florida.

**What we saw in the run**
- The q18 extraction has 29 rows, but 13 state names are empty and several populations are -1.
- Arizona, Illinois, Massachusetts, New York, Ontario, and Oregon are missing entirely.
- Florida averages 221,120 because a valid 442,241 value is averaged with an Orlando -1 sentinel; Texas retains only Houston and becomes 2,314,157.
