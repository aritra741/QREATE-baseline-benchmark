# q18: What is the average city population for each state?
## Query contract
**Natural language:** What is the average city population for each state?

**Reference SQL**
```sql
SELECT state_name, AVG(population) AS avg_population FROM city WHERE state_name != '' GROUP BY state_name
```

**QuWARTS compiled SQL**
```sql
SELECT state_name, AVG(population) AS avg_population FROM city WHERE state_name != '' GROUP BY state_name
```

The SQL contracts are equivalent unless the two SQL blocks visibly differ. Therefore, documented failures below are downstream of intent/compilation.

### Why QuWARTS differs
- **Pipeline stage:** Population date and area
- **Root cause:** QuWARTS used population numbers from different years or different areas.
- **Why the system made this choice:** It saved one population number without also saving the date or whether it covered the city or the larger metro area.
- **Why the checks did not catch it:** All the values looked like reasonable population numbers and appeared in the source text.
- **Why this query failed:** Every state group was present, but the wrong population version changed six averages.

**What I found in the final and working tables**
- The city table has 29 rows and q18 reproduces all 22 gold state groups with no extras.
- Wrong examples include New York 8,804,190 versus 8,258,035, Utah 1,257,936 versus 200,133, and Texas averaging 2,072,845.33 versus 1,684,387.
- Every state name matches. The errors therefore come from the population values, not from the grouping or calculation.

### Why DocETL differs
- **Pipeline stage:** Missing states and populations
- **Root cause:** DocETL left many state names empty and marked some populations as unknown.
- **Why the system made this choice:** Inside the city table, DocETL used -1 to mark an unknown population. It did not remove that marker before calculating averages.
- **Why the checks did not catch it:** The final table shows averages, not the original -1 values. The checks did not notice that an average included a missing-value marker.
- **Why this query failed:** Empty state names removed groups. In Florida, a hidden -1 marker lowered the displayed average.

**What I found in the final and working tables**
- The intermediate city table has 29 rows. Nine state names are empty and eight populations use -1 to mean missing. The final table shows averages, not the original -1 values.
- Arizona, Illinois, Massachusetts, New York, Ontario, and Oregon are missing entirely.
- Florida averages 221,120 because the valid value 442,241 is averaged with Orlando's -1 missing marker. Texas keeps only Houston and becomes 2,314,157.
