# q14: How many championships has each owner’s team(s) won in total?
## Query contract
**Natural language:** How many championships has each owner’s team(s) won in total?

**Reference SQL**
```sql
SELECT ownership, SUM(championship) AS total_championships FROM team WHERE ownership != '' GROUP BY ownership
```


The SQL contracts are equivalent unless the two SQL blocks visibly differ. Therefore, documented failures below are downstream of intent/compilation.

### Why QuWARTS differs
- **Pipeline stage:** Owner names used for scoring
- **Root cause:** The scoring data changes team owner names by using a separate owner table, but the question does not ask either system to use that table.
- **Why the system made this choice:** The requested schema has a team ownership field but no owner lookup table. QuWARTS therefore uses ownership text from its team rows, including old, legal, and short names.
- **Why the checks did not catch it:** Those values are valid owner text. The working contract contains no link to the separate owner-name list used while building the gold table.
- **Why this query failed:** Related owner names became separate groups. Extra team rows added more owners. Part of this error comes from a scoring rule that was hidden from both systems.

**What I found in the final and working tables**
- Before scoring, the ground-truth process replaces 15 team owner names with names from a separate owner table.
- QuWARTS emits variants such as Dan Gilbert, DeVos family, Joseph Tsai, Jerry Buss, Stan Kroenke, and Ted Leonsis through Monumental Sports & Entertainment instead of the gold person-name surfaces.
- The 42-row team table also includes old or unclear owners such as Fred Zollner, Liberty Media, owner, owned, and 20%. Vulcan Inc. receives title count 1977 because a year was used as a count.
- These failures produce 30 unmatched groups and 21 missing gold groups.

### Why DocETL differs
- **Pipeline stage:** Owner names used for scoring
- **Root cause:** DocETL reads owner names from team documents, while the scoring data changes them by using a separate owner table.
- **Why the system made this choice:** The reference query requests only a team table, so this DocETL run builds only that table. It does not build or join the separate owner lookup used while creating the gold table.
- **Why the checks did not catch it:** Names such as Dan Gilbert and Joseph Tsai are reasonable answers from team documents.
- **Why this query failed:** These names did not exactly match the scorer's longer names. Old owners and missing rows caused more errors.

**What I found in the final and working tables**
- Examples include Dan Gilbert versus gold Daniel Gilbert, Joseph Tsai versus Joseph Chung-Hsin Tsai, and Jerry Buss versus Jerry Buss (from 1979).
- Historical owners such as Donald Sterling, Fred Zollner, George Shinn, and Robert Breitbard become extra groups.
- Four team documents produce no row, including Milwaukee, New York, Utah, and Washington. This removes more owners.
- DocETL has 19 missing gold owner groups, 11 extras, and wrong totals for Clay Bennett, Glen Taylor, and Micky Arison.
