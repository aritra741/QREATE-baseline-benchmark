# q15: Among teams with at least one championship, what is the average number of championships for teams in each city?
## Query contract
**Natural language:** Among teams with at least one championship, what is the average number of championships for teams in each city?

**Reference SQL**
```sql
SELECT location, AVG(championship) AS avg_championships FROM team WHERE championship >= 1 AND location != '' GROUP BY location
```

**QuWARTS compiled SQL**
```sql
SELECT location, AVG(championship) AS avg_championships FROM team WHERE championship >= 1 AND location != '' GROUP BY location
```

The SQL contracts are equivalent unless the two SQL blocks visibly differ. Therefore, documented failures below are downstream of intent/compilation.

### Why QuWARTS differs
- **Pipeline stage:** Current locations and title totals
- **Root cause:** QuWARTS kept location variants and wrong title totals instead of one benchmark row for each team.
- **Pipeline behavior behind it:** The working table stores a location and title number, but it stores no date that could identify the current version of each fact.
- **Why validation allowed it:** Location variants and wrong totals still have valid text and number types. The checks could not identify the benchmark version from type alone.
- **How it affected the result:** The question kept the wrong versions of teams. Different city names split groups, and wrong totals changed the averages.

**What I found in the final and working tables**
- Location variants include Detroit→Auburn Hills, New York City→Manhattan, Philadelphia→Philadelphia metropolitan area, and Washington→Washington, D.C.
- Seven gold cities are missing and six unmatched city labels are added.
- Aligned values expose wrong historical totals: Cleveland 1→6, San Antonio 5→7, and San Francisco 7→6.
