# q3: Among colleges with more than one player in the league, what is the highest number of MVP awards won by any of its players?
## Query contract
**Natural language:** Among colleges with more than one player in the league, what is the highest number of MVP awards won by any of its players?

**Reference SQL**
```sql
SELECT college, MAX(mvp_awards) AS max_mvp_awards FROM player WHERE college != '' GROUP BY college HAVING COUNT(*) > 1
```

### Why QuWARTS differs
- **Pipeline stage:** College names and MVP counts
- **Root cause:** QuWARTS used several names for the same college and missed most MVP counts.
- **Pipeline behavior behind it:** The selected working table did not run a name-cleaning step that joins short names, full names, and mascot names.
- **Why validation allowed it:** UCLA and UCLA Bruins are both valid text. The basic type check does not test whether two labels refer to the same college.
- **How it affected the result:** Players from one college were split into several groups. This changed which colleges had more than one player and changed the highest MVP value.

**What I found in the final and working tables**
- College is missing from 38 of 160 rows. MVP count is missing from 120 rows.
- Aliases such as UCLA Bruins versus UCLA, Duke Blue Devils versus Duke University, and Kentucky Wildcats versus University of Kentucky appear as missing/extra pairs.
- The question needs more than one player with the exact same college name. Different names for one college change which groups qualify. Eight matching groups then have a wrong or missing highest value.
