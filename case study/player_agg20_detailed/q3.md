# q3: Among colleges with more than one player in the league, what is the highest number of MVP awards won by any of its players?
## Query contract
**Natural language:** Among colleges with more than one player in the league, what is the highest number of MVP awards won by any of its players?

**Reference SQL**
```sql
SELECT college, MAX(mvp_awards) AS max_mvp_awards FROM player WHERE college != '' GROUP BY college HAVING COUNT(*) > 1
```

```sql
SELECT college, MAX(mvp_awards) AS max_mvp_awards FROM player WHERE college != '' GROUP BY college HAVING COUNT(*) > 1
```

The SQL contracts are equivalent unless the two SQL blocks visibly differ. Therefore, documented failures below are downstream of intent/compilation.

### Why QuWARTS differs
- **Pipeline stage:** Entity resolution and sparse measure extraction
- **Root cause:** College names were not resolved to one identity, and most MVP counts were missing.
- **Why the system made this choice:** The raw view keeps the name found in each document. There is no shared college resolver that merges mascot, short, and full university names.
- **Why the checks did not catch it:** The grouping check only tests that output keys are unique. It does not know that UCLA Bruins and UCLA are the same college.
- **Why this query failed:** Alias splitting changes which exact strings have more than one player. HAVING therefore selects the wrong groups before MAX sees the sparse MVP values.

**What we saw in the run**
- The player table has 38/160 NULL colleges and 120/160 NULL mvp_awards.
- Aliases such as UCLA Bruins versus UCLA, Duke Blue Devils versus Duke University, and Kentucky Wildcats versus University of Kentucky appear as missing/extra pairs.
- Because the query requires more than one row per exact college string, alias splitting changes membership before MAX is evaluated; eight aligned groups then have wrong or NULL maxima.
