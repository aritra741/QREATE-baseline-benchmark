# q4: Among players with a known position, what is the total number of MVP awards won at each position?
## Query contract
**Natural language:** Among players with a known position, what is the total number of MVP awards won at each position?

**Reference SQL**
```sql
SELECT position, SUM(mvp_awards) AS total_mvp_awards FROM player WHERE position IN ('Frontcourt', 'Backcourt') GROUP BY position
```

**QuWARTS compiled SQL**
```sql

FROM "player" AS "t2"
WHERE ("t2"."position" = 'Frontcourt' OR "t2"."position" = 'Backcourt')
GROUP BY "t2"."position"
```
