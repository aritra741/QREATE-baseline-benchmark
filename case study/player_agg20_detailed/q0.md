# q0: Among players with a known position, what is the average age at each position?
## Query contract
**Natural language:** Among players with a known position, what is the average age at each position?

**Reference SQL**
```sql
SELECT position, AVG(age) AS avg_age FROM player WHERE position IN ('Frontcourt', 'Backcourt') GROUP BY position
```

**QuWARTS compiled SQL**
```sql
SELECT "t2"."position", AVG("t2"."age") AS "avg_age"
FROM "player" AS "t2"
WHERE ("t2"."position" = 'Frontcourt' OR "t2"."position" = 'Backcourt')
GROUP BY "t2"."position"
```

The SQL contracts are equivalent unless the two SQL blocks visibly differ. Therefore, documented failures below are downstream of intent/compilation.

### Why QuWARTS differs
- **Pipeline stage:** Position names
- **Root cause:** QuWARTS kept detailed positions but the question needed two broad position groups.
- **Why the system made this choice:** QuWARTS kept names such as center and point guard because those names came directly from the documents.
- **Why the checks did not catch it:** The names are real basketball positions, so the checks did not see them as wrong.
- **Why this query failed:** The question accepts only Frontcourt or Backcourt. Neither name was present, so no player reached the average calculation.

**What I saw in the run**
- The selected QuWARTS player table contains 160 rows, with positions such as forward (17), point guard (14), center (14), power forward (9), and shooting guard (9), but zero Frontcourt or Backcourt values.
- Age is missing from 91 of 160 rows. This does not affect this result because the position rule removes every row first.
- The saved question uses the correct position rule. The error happened in the extracted data, not in the question.
