# q13: How many teams founded before 1970 are based in each city?
## Query contract
**Natural language:** How many teams founded before 1970 are based in each city?

**Reference SQL**
```sql
SELECT location, COUNT(*) AS team_count FROM team WHERE founded_year < 1970 AND location != '' GROUP BY location
```

**QuWARTS compiled SQL**
```sql
SELECT location, COUNT(*) AS team_count FROM team WHERE founded_year < 1970 AND location != '' GROUP BY location
```

The SQL contracts are equivalent unless the two SQL blocks visibly differ. Therefore, documented failures below are downstream of intent/compilation.

### Why QuWARTS differs
- **Pipeline stage:** Row identity, location resolution, and event years
- **Root cause:** The team relation contains historical and duplicate rows, noncanonical cities, and wrong founded years.
- **Why the system made this choice:** The high-recall raw view does not collapse several team-like rows into one current team record.
- **Why the checks did not catch it:** A city or year can be source-backed and type-correct even when it describes a former location or a different event.
- **Why this query failed:** Exact city keys split groups, and wrong founded years remove Houston and Philadelphia before COUNT.

**What we saw in the run**
- The same 42-row team table includes historical subentities and location variants such as Auburn Hills, Manhattan, Phoenix, Arizona, and Washington, D.C.
- Nine gold cities are missing and four unmatched city labels are added.
- Houston and Philadelphia are both assigned founded_year=1976 rather than their gold pre-1970 years, so the correct predicate excludes them.
- Aligned groups all have the correct count, showing that the dominant q13 failure is record/key selection rather than COUNT arithmetic.

### Why DocETL differs
- **Pipeline stage:** Sentinel handling and current-fact selection
- **Root cause:** Unknown founded years became -1, while the Map step selected historical locations and years.
- **Why the system made this choice:** The prompt uses -1 for unknown numbers and has no temporal resolver for one current team record.
- **Why the checks did not catch it:** -1 is a valid number and also satisfies the less-than-1970 filter. Historical locations are valid strings.
- **Why this query failed:** Unknown teams become false positives, current teams disappear under old city names, and wrong years remove valid groups.

**What we saw in the run**
- Charlotte, Miami, and New Orleans have founded_year=-1 and therefore become false-positive pre-1970 teams.
- Detroit is represented as Fort Wayne; Brooklyn as New Jersey; Phoenix and Washington carry state/district suffixes.
- San Antonio is assigned 1973 rather than 1967 and fails the filter; Sacramento has an empty location and the Knicks document is absent.
- Seven gold cities are missing and seven unmatched cities are added despite the row count coincidentally equaling gold.
