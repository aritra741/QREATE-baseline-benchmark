# q11: How many players aged 20 to 40 are there for each nationality?
## Query contract
**Natural language:** How many players aged 20 to 40 are there for each nationality?

**Reference SQL**
```sql
SELECT nationality, COUNT(*) AS player_count FROM player WHERE age BETWEEN 20 AND 40 AND nationality != '' GROUP BY nationality
```

**QuWARTS compiled SQL**
```sql
SELECT "t2"."nationality", COUNT(*) AS "player_count"
FROM "player" AS "t2"
WHERE (("t2"."age" >= 20 AND "t2"."age" <= 40) AND "t2"."nationality" != '')
GROUP BY "t2"."nationality"
```

The SQL contracts are equivalent unless the two SQL blocks visibly differ. Therefore, documented failures below are downstream of intent/compilation.

### Why QuWARTS differs
- **Pipeline stage:** Age derivation and extraction coverage
- **Root cause:** The pipeline extracted ages mentioned in the articles instead of deriving age at the fixed reference year from birth data.
- **Why the system made this choice:** The query contract asks for age, so the raw extractor can fill that field directly. It does not require birth date as an input to a checked calculation.
- **Why the checks did not catch it:** An article-era age is still a valid number with a source span. The checks have no cross-field rule that age must agree with birth date and 2026.
- **Why this query failed:** Old ages move older players into the 20 to 40 range, while missing ages remove valid players. Nationality variants then split the remaining groups.

**What we saw in the run**
- The player table has 91/160 NULL ages and 53 NULL nationalities.
- Seven gold nationality groups are missing and six country/demonym variants are extra.
- False age inclusions include Guy Rodgers 90→35, Tim Duncan 50→34, Dino Rađa 58→23, and Kobe Bryant 47→35. These rows pass the otherwise-correct 20 to 40 filter.
- American is undercounted 49→40 and French 2→1.

### Why DocETL differs
- **Pipeline stage:** Age derivation and missing-value handling
- **Root cause:** The per-question Map step asked only for age, so it copied article-era ages and used -1 when age was unclear.
- **Why the system made this choice:** The prompt did not require a birth-date calculation or return the facts used for that calculation.
- **Why the checks did not catch it:** Article-era ages and -1 are valid numbers. No later rule checks them against the 2026 reference year.
- **Why this query failed:** Wrong ages change filter membership, missing ages remove records, and nationality variants change the final groups.

**What we saw in the run**
- The q11 extraction has 49/133 age=-1 and 45 empty nationalities.
- Four gold groups are missing and four unmatched groups are added.
- Article-era or unrelated ages move older players into range. Examples are Mark Price 61→36, Magic Johnson 66→36, and Michael Jordan 62→38. Several genuinely qualifying players are absent or have sentinel ages.
- American is close but low (49→48), French is 2→1, and Greek is overcounted 1→2.
