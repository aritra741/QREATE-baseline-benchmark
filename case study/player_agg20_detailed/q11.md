# q11: How many players aged 20 to 40 are there for each nationality?
## Query contract
**Natural language:** How many players aged 20 to 40 are there for each nationality?

**Reference SQL**
```sql
SELECT nationality, COUNT(*) AS player_count FROM player WHERE age BETWEEN 20 AND 40 AND nationality != '' GROUP BY nationality
```

**QuWARTS compiled SQL**
```sql
SELECT "t2"."nationality", COUNT(*) AS "player_count"
FROM "player" AS "t2"
WHERE (("t2"."age" >= 20 AND "t2"."age" <= 40) AND "t2"."nationality" != '')
GROUP BY "t2"."nationality"
```

The SQL contracts are equivalent unless the two SQL blocks visibly differ. Therefore, documented failures below are downstream of intent/compilation.

### Why QuWARTS differs
- **Pipeline stage:** Age calculation
- **Root cause:** QuWARTS copied ages mentioned in articles instead of calculating age in 2026 from birth information.
- **Why the system made this choice:** The question asked for age, so QuWARTS filled that value directly. It did not require birth information for a checked calculation.
- **Why the checks did not catch it:** An old age from an article is still a normal number and appears in the source text.
- **Why this query failed:** Old ages let some older players pass the 20 to 40 rule. Missing ages removed other players, and nationality names split more groups.

**What I saw in the run**
- Age is missing from 91 of 160 rows. Nationality is missing from 53 rows.
- Seven gold nationality groups are missing and six country/demonym variants are extra.
- False age inclusions include Guy Rodgers 90→35, Tim Duncan 50→34, Dino Rađa 58→23, and Kobe Bryant 47→35. These rows pass the otherwise-correct 20 to 40 filter.
- American is undercounted 49→40 and French 2→1.
