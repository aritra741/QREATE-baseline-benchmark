# q19: Among cities with more than one million people, what is the highest GDP in each state?
## Query contract
**Natural language:** Among cities with more than one million people, what is the highest GDP in each state?

**Reference SQL**
```sql
SELECT state_name, MAX(gdp) AS max_gdp FROM city WHERE population > 1000000 AND state_name != '' GROUP BY state_name
```

**QuWARTS compiled SQL**
```sql
SELECT state_name, MAX(gdp) AS max_gdp FROM city WHERE population > 1000000 AND state_name != '' GROUP BY state_name
```

The SQL contracts are equivalent unless the two SQL blocks visibly differ. Therefore, documented failures below are downstream of intent/compilation.

### Why QuWARTS differs
- **Pipeline stage:** GDP units and population area
- **Root cause:** QuWARTS mixed GDP values written in dollars, millions, and billions.
- **Why the system made this choice:** It kept the number found in each document without changing all values to one unit.
- **Why the checks did not catch it:** Each value was a number and appeared in the source text. The checks did not compare the units.
- **Why this query failed:** The total added values that used different units. A metro population also caused Utah to pass a rule meant for city population.

**What I saw in the run**
- GDP scaling errors include Arizona 362,000→362,000,000,000, Illinois 689,000→689,000,000,000, and Pennsylvania 518.5→518,500,000,000.
- Utah is an extra group because Salt Lake City population is extracted as 1,257,936 instead of 200,133 and incorrectly passes the >1,000,000 filter.
- California receives GDP 1,000,000 even though the ground truth is empty. Several other states have no GDP value.

### Why DocETL differs
- **Pipeline stage:** GDP units and missing states
- **Root cause:** DocETL saved GDP as a number without saving its unit. It also left some state names empty.
- **Why the system made this choice:** It removed commas from numbers but did not change millions and billions to one common unit.
- **Why the checks did not catch it:** Values on different scales are still numbers, and empty state names were allowed.
- **Why this query failed:** Some cities disappeared because the state was empty. Other GDP values were added even though they used different units.

**What I saw in the run**
- Arizona, Illinois, and Ontario source rows have blank state names and disappear; Florida is extra because Orlando population is extracted as 2,509,831.
- Pennsylvania GDP is 52,889 instead of 518.5 and Texas is 189,056.3 despite blank gold GDP.
- California and New York also receive nonblank GDP values where the benchmark gold result is blank.
