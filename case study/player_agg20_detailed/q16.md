# q16: What is the average owner age for each nationality?
## Query contract
**Natural language:** What is the average owner age for each nationality?

**Reference SQL**
```sql
SELECT nationality, AVG(age) AS avg_age FROM owner GROUP BY nationality
```

**QuWARTS compiled SQL**
```sql
SELECT nationality, AVG(age) AS avg_age FROM owner GROUP BY nationality
```

The SQL contracts are equivalent unless the two SQL blocks visibly differ. Therefore, documented failures below are downstream of intent/compilation.

### Why QuWARTS differs
- **Pipeline stage:** Owner coverage and age calculation
- **Root cause:** QuWARTS built rows for only some owners and did not calculate age from birth information.
- **Why the system made this choice:** The document sorting and extraction can miss documents or fields. QuWARTS also accepts ages stated directly in articles.
- **Why the checks did not catch it:** A stated age is a normal number. There was no required check against birth information and 2026.
- **Why this query failed:** The average used too few owners. Missing ages gave empty results for some groups, and different nationality wording created extra groups.

**What I saw in the run**
- The owner table has 11 rows. Five ages are missing.
- Sicilian descent and U.S. are extra nationality groups. The other three ground-truth names are present.
- The American average is 67.0 instead of 72.1429. Israeli-American and Taiwanese-Canadian have no result because their rows have no age.

### Why DocETL differs
- **Pipeline stage:** Age values and missing numbers
- **Root cause:** DocETL confused a birth year with an age and used -1 for missing ages.
- **Why the system made this choice:** The age field only had to contain a number. The instruction did not require a sensible age range or a birth-date calculation.
- **Why the checks did not catch it:** 1959 and -1 are both numbers, so the basic check accepted them.
- **Why this query failed:** These values were averaged as real ages, making the American result far too large.

**What I saw in the run**
- The q16 output includes age=1959 for one American owner and five age=-1 rows.
- These values produce an American average of 211.25 instead of 72.1429.
- Israeli-American and Taiwanese-Canadian are missing; Canadian and an empty nationality group are added.
