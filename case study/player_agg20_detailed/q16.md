# q16: What is the average owner age for each nationality?
## Query contract
**Natural language:** What is the average owner age for each nationality?

**Reference SQL**
```sql
SELECT nationality, AVG(age) AS avg_age FROM owner GROUP BY nationality
```

```sql

```

The SQL contracts are equivalent unless the two SQL blocks visibly differ. Therefore, documented failures below are downstream of intent/compilation.

### Why QuWARTS differs
- **Pipeline stage:** Owner coverage and age derivation
- **Root cause:** Only part of the owner relation was materialized, and age was not derived from a checked birth fact at the reference year.
- **Why the system made this choice:** Content routing and high-recall extraction can still miss documents or fields. The raw view accepts direct age mentions and nationality wording.
- **Why the checks did not catch it:** A direct age and a descriptive nationality are type-correct. There is no required birth-date consistency check.
- **Why this query failed:** AVG uses a small set of owners, while missing ages create null group values and nationality wording creates extra groups.

**What we saw in the run**
- The owner table has 11 rows; five ages are NULL.
- Sicilian descent and U.S. are extra nationality groups, while the canonical three gold keys otherwise remain present.
- American averages 67.0 versus 72.1429, and Israeli-American and Taiwanese-Canadian return NULL because their retained rows have no age.

- **Why the checks did not catch it:** 1959 and -1 are both valid numbers, so neither is rejected before AVG.
