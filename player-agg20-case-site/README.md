# QuWARTS case study site

Static site that compares QuWARTS and DocETL on 20 Player questions.

## Local

```bash
cd player-agg20-case-site
npm install
npm run dev
```

## Deploy on Vercel

```bash
cd player-agg20-case-site
npx vercel
```

Or set the Vercel project root to `player-agg20-case-site`.

- Build command: `npm run build`
- Output folder: `dist`
